# Café 90’s

GitHub Pages opens the live storefront at https://cafe-90s-chathannoor.niftypancake128.chatgpt.site/. The app directory contains the café storefront, owner dashboard and ordering endpoints. The public directory contains the official menu and photos. D1 migrations are in drizzle. The backend and authenticated owner dashboard run on Sites. This repository is a source snapshot. Changes pushed here do not automatically redeploy Sites.
